## Executive finding

The original HISE project’s main script declares a sizeable chord-engine design, but its saved authoritative `ScriptProcessor1.js` contains no `onNoteOn`, `onNoteOff`, `onController`, or `onControl` callback and no calls to its note-generation/sending helpers. In particular, searches show `ceCalculateNotes` only at its definition in the active script (no call site), not an event or UI call. The other script processor has empty callbacks and sits inside the Sine Wave Generator. Therefore, the original HISE project source does **not** establish working MIDI chord-generation behavior. The project settings request MIDI input/output, and the script contains intended chord tables and voice helpers, but those are not proof that this project’s runtime emits those notes. Several features named in the product brief (a general scale/key system, recorder, trial/licensing UI, Help & Feedback) are not present in the original HISE project’s inspected script/configuration. The separate working FL release is now partially inspected at the embedded-source level; its actual host behavior still needs safe capture.

## Licensing path mechanics found in HISE source

The generic HISE framework’s frontend data directory is `<appDataRoot>/<FrontendHandler company>/<project>`. For the generated ChordEngine factory strings, that is `My Company/ChordEngine`; on a normal user-scoped macOS build the root is `~/Library/Application Support`, unless the build uses the common/system data-folder macro. The frontend key file is `<appDataRoot>/My Company/ChordEngine/ChordEngine.license` on macOS. The backend `ScriptUnlocker` key-file path is `<appDataRoot>/My Company/ChordEngine/ChordEngine.license` (it constructs company/project/project plus the `.license` extension). The project’s `UseGlobalAppDataFolderMacOS=No` is consistent with user-scoped use, but the exported binary macro should be checked before relying on a deployed path. This describes HISE framework mechanics; it does **not** establish that ChordEngine currently uses a trial/online licensing product.
