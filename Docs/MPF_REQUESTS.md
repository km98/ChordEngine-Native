# Requests for the Music-Prod Plugin Framework (mpf)

When the JUCE-free rebuild started, `~/Documents/MusicProd-Plugin-Framework`
did not exist, so ChordEngine 0.6.0 carries its own platform layer and format
adapters. By 2026-10-22 the repository exists (first commits `0131281`,
`10efcd0`, `af91d69`: AudioUnitSDK 1.4.0 + VST 3 SDK **3.8.1**, Plugin
Studio wrapper). ChordEngine does not depend on it and this repo has not
edited it. Below is what ChordEngine would need from mpf before moving onto
it; each item names the ChordEngine code that already does it, as a
reference implementation.

## Platform layer

1. **One OS layer for macOS and Windows**: JSON with int/real distinction and
   ordered keys, CSPRNG hex, SHA-256, computer/OS name, per-user app-data
   folder, atomic file writes, blocking HTTP with connect/total timeouts,
   response size cap and a "no redirects" mode (WinHTTP / NSURLSession).
   *ChordEngine: `Source/Platform/`.*
2. **Main-thread dispatch, a worker queue and main-thread timers** that work
   inside a host on Windows (message-only window; jobs queued before the
   host's UI thread is known must wait, not run on a worker).
   *`PlatformWin.cpp`, `WorkerQueue.cpp`.*
3. **Per-binary Objective-C class names** so two bundles of one product (AU
   and VST3, or MIDI FX and instrument) can load in one host process.
   *`Source/Platform/ObjCNames.h`.*

## Format adapters

4. **AU MIDI effect (`aumi`) with MIDI output**: MIDI out through the host's
   MIDI event list block when installed, else the legacy output callback,
   never both (Logic installs both; sending on both duplicates notes).
5. **AU instrument (`aumu`) with refused channel counts**: explicit
   `{0,1}`/`{0,2}` configs, named output bus, `ValidFormat`/`Initialize`
   refusing other layouts.
6. **Single-component VST3 with `IMidiMapping`** and stable, caller-chosen
   parameter IDs (needed to keep JUCE-era IDs: bypass `'byps'`, MIDI CC
   parameters `0x6d636d00 + ch*130 + cc`), event buses with fixed names,
   host bypass persisted in state.
7. **Legacy JUCE state migration helpers**: read the AU ClassInfo key
   `jucePluginState`, strip the VST3 `JUCEPrivateData` trailer
   (int64 0, ValueTree, int64 size, marker), so every product leaving JUCE
   can open old projects. *`Source/VST3/ChordEngineVST3.mm`,
   `Source/AU/ChordEngineAU.mm`.*
8. **SDK version alignment**: ChordEngine is on VST 3 SDK 3.8.0_build_66,
   mpf on 3.8.1. One pinned version for all Music-Prod products, with the
   provenance table and notices file generated by mpf.

## UI toolkit

9. **A platform-neutral widget/paint layer** with AppKit and Win32/Direct2D
   back ends, uniform scaling from a design space, private font loading,
   offscreen PNG snapshots, keyboard focus and navigation. ChordEngine's
   editor is AppKit-only today (`Source/UI/`); its Windows editor plan is in
   `Docs/NATIVE_REBUILD.md`.
10. **MIDI file drag-out** from the editor into the DAW on both platforms
    (`NSFilePromiseProvider` / OLE `DoDragDrop` with `CF_HDROP`).

## Product services

11. **Music-Prod account, licence key, trial and update clients** as a shared
    module with an injectable transport and auth service (ChordEngine's editor
    tests cannot click SIGN IN today because the processor always uses the
    real auth service). *`Source/Licensing/`, `Source/Updates/`.*

## Test and release tools

12. **In-process AU probe** (register the built bundle with
    `AudioComponentRegister`, no install) and a **VST3 host test** on the SDK
    hosting helpers. *`Tests/AUProbe.mm`, `Tests/VST3HostTest.mm`.*
13. **Real-time safety probe** (`DYLD_INSERT_LIBRARIES` interposer counting
    malloc/free, including `malloc_type_*`, and pthread/os_unfair locks on the
    audio thread, with a positive control). *`Tests/RtProbe.c`.*
14. **No-JUCE gate** over sources and linked symbols. *`Tools/CheckNoJuce.sh`.*
15. **auval without touching the user's plug-in folders**: mpf's
    `tools/run-auval.sh` installs a temporary copy into the user domain; a
    variant that never writes to `~/Library/Audio/Plug-Ins` (for Macs where
    that is not allowed) would be welcome.
16. **Installer packaging** with `BundleIsRelocatable=false`, BOM mode gates,
    PkgInfo/AU-version/bundle checks. *`Tools/PackageMacDMG.sh`,
    `Tools/CheckBundles.sh`.*
